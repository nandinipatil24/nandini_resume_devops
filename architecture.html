Resume Website Architecture

This page describes the full architecture of my resume website, hosted entirely for free and managed using DevOps principles.

🔧 Tools Used

  • GitHub: Version control and source code management
  • GitHub Codespaces: Cloud development environment
  • GitHub Pages: Free hosting and automatic deployment
  • HTML + CSS: Lightweight, fast, zero-cost frontend
  • UptimeRobot (Optional): Free monitoring for uptime

📐 Architecture Diagram

User Browser → GitHub Pages (Static Hosting)
                   ↑
                   │
           GitHub Repository
                   ↑
                   │
             Git Push (Changes)

🚀 Why This Architecture?

  • 100% Free hosting using GitHub Pages
  • No servers, no cloud cost, no backend required
  • Simple, fast, and globally accessible
  • Shows DevOps understanding: version control, automation, documentation
